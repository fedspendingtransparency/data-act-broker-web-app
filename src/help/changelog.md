#### September 30, 2026{section=changelog}
In this release of the Broker, we:

* Implemented the following related to GSDM 1.2
    * Updated the country code loader and transaction data to distinguish freely associated states vs territories.
    * Added support for the new action types (see GSDM for details).
    * Added support for the new assistance types (see GSDM for details).
* Implemented the following related to GSDM 1.3
    * Updated the rule descriptions for C9, FABS 31.4, FABS 31.5, and FABS 31.7.
    * Split FABS 47 and FABS 48 into multiple parts (see GSDM for details).
