#### November 24, 2026{section=changelog}
In this release of the Broker, we:

* Pushed the final changes for GSDM 1.2
    * Updated B11 to exclude Budget Object Class 920/9200.
    * Updated D2 to include AwardAmountBasisCode, AwardAmountBasisName, AwardRecipientBasisCode, and AwardRecipientBasisName based from FABS.
* Fine-tuned the logic of C23 to apply when the ATA and AID are the same, when the ATA is the submitting agency, or when the ATA is blank.
* Updated the GSDM Warning and Error Report Specification (WERS) link on the Help page to version 1.3.
